# Publicación rápida en Netlify

Este ZIP está preparado para Netlify Drop.

1. Descomprime `la-junta-netlify-dist.zip`.
2. Arrastra la carpeta descomprimida a https://app.netlify.com/drop.
3. No configures una carpeta `dist`: `index.html` ya está en la raíz.

Si usas el proyecto completo, arrastra únicamente su carpeta `dist` o conecta el repositorio con `netlify.toml`; en ese caso la carpeta de publicación es `dist`.
